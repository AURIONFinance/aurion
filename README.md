# AURION Finance

AURION Finance is an institutional-grade financial network connecting capital, tokenized assets, financial intelligence, and on-chain settlement.

## Network

AURION Finance is building its on-chain financial infrastructure on **BNB Chain (BNB Smart Chain / BSC)**.

## Products

- **AURION Access** — On-chain entry layer for the AURION Finance network.
- **AURION Prime** — Structured strategy product for on-chain financial participation.
- **AURION Intelligence** — Multi-model financial intelligence layer.
- **Portfolio** — Position management and on-chain settlement interface.

## Repository

This repository contains project resources and configuration for AURION Finance on **BNB Chain**.
